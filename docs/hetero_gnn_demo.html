核心公式一覽
SAGEConv（每層、每種邊）
out_X_vi = W_n × MEAN( h_u for u in N_X(vi) )
            + W_s × h_vi

h_vi_new = ReLU( sum of out_X_vi for all edge types X )
N_X(vi) 代表透過邊 X 連到 vi 的所有鄰居節點集合。
每種邊（similar / author / category）各有獨立的 W_n 和 W_s。
demo 中共用同一組數值以便計算。
Loss（加權多任務）
w = n_impressions / sum(n_impressions)

rate_loss = sum( w_i × (pred_i - true_i)^2 )

wt_loss = sum( w_i × Huber(pred_log_i, true_log_i, delta=1) )

total_loss = rate_loss + wt_loss
Huber loss：diff < delta 時用平方，否則改用線性，防止 watch_time 極端值爆炸。

mean_watch_time 的特殊處理
為什麼用 log 空間？
watch_time 分布高度右偏：少數熱門影片的觀看時長可能是平均值的 100 倍以上。 直接在原始空間訓練，MSE 會被這些極端值主導，模型只會一直猜高值。
做法：訓練前先轉換 target = log1p(watch_time)，讓目標值接近常態； 推論時再 pred_sec = expm1(pred_log) 還原。
為什麼用 Huber Loss（δ = 1.0）？
即使在 log 空間，仍有部分極端影片。MSE 對大誤差是二次懲罰，一個異常值就能主導整批梯度。 Huber 切換策略如下：
L(x) = x² / 2 ← 若 |x| ≤ δ（誤差小，用平方：梯度光滑）
L(x) = δ × ( |x| − δ/2 ) ← 若 |x| > δ（誤差大，切換線性：不讓極端值爆炸）

其中 x = pred_log − true_log，δ = 1.0

範例：誤差 x = 3.0（log 空間）
MSE 損失： 3.0² = 9.00，梯度 = 6.0
Huber 損失：1.0 × (3.0 − 0.5) = 2.50，梯度 = 1.0（縮小 6 倍）

為什麼 v2（val）和 v3（test）也要參與 Forward Pass？

在 Layer 2 計算 v0 的 embedding 時，需要 c0 在 Layer 1 的結果 h_c0_L1。
而 h_c0_L1 = ReLU( W_n × MEAN(h_v0, h_v1, h_v2, h_v3) + W_s × h_c0 )
c0 聚合了全部四個影片，包含 v2 和 v3 的初始特徵。

因此 v2、v3 雖然不進入 loss，其特徵仍透過共用鄰居（c0）影響 v0/v1 的最終 embedding。
Forward Pass 全圖（4 個影片都算）：
pred_v0 = 0.634, pred_v1 = 0.600 ← train_mask = True，進入 loss
pred_v2 = ?, pred_v3 = ? ← train_mask = False，不進入 loss

loss = (0.634 - 0.600)^2 + (0.600 - 0.700)^2 = 0.01116

Transductive Learning — 測試節點在圖中，但不是 leakage
什麼是 Transductive Learning？
模型訓練時看到的是一張固定的完整圖——所有節點（包含 val、test）都在圖中。 它們的特徵（features X）對訊息傳遞可見，但它們的標籤（labels Y）從不進入 loss。
這是 GCN / GraphSAGE 的標準半監督做法，也稱為「transductive node classification」。
為什麼不算 leakage？
Leakage 的定義：把「測試時才會知道的資訊」偷偷帶進訓練。
v3 的特徵 X（封面向量、描述文字等）在影片上架第一天就存在，並非未來資訊。
v3 的標籤 Y（實際 like_rate、watch_time）才是未來才有的資訊——這些從未進入 loss。
結論：X 可見 ≠ leakage；Y 進 loss 才是 leakage。
與 Inductive Learning 的差異，以及 Cold Start
Transductive（本 demo）：圖結構訓練時固定，推論只在已知節點上進行。
Inductive（GraphSAGE 原始設計）：支援訓練結束後加入全新節點，模型對未見結構做推論。

若要對全新影片做 Inductive 推論，需同時具備：
① 既有作者（author embedding 已在訓練圖中）
② 既有類別（category embedding 已在訓練圖中）
③ 至少 1 個 kNN 鄰居（cosine 相似的既有影片，提供 similar_to 訊息）

若作者是全新的（無任何 train 標籤均值），10 維 author 特徵中的 label-mean 欄位將缺失——這才是真正的 Cold Start 問題。
